# BMI Calculator

A simple Python application to calculate Body Mass Index.

## Features

- Weight input
- Height input
- BMI calculation
- BMI category detection
- Input validation

## Formula

BMI = Weight / (Height * Height)

## Tech Stack

- Python

## How to Run

python bmi_calculator.py
