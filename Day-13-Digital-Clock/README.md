# Digital Clock

A real-time digital clock built using Python.

## Features

- Live clock
- Current date
- Day name
- Automatic time updates
- Keyboard interrupt support

## Tech Stack

- Python
- Datetime Module
- Time Module

## How to Run

python digital_clock.py

## Concepts Learned

- Python modules
- Datetime
- Time formatting
- While loops
- Exception handling
- String formatting
