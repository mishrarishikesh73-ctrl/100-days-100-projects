# Password Generator

A Python application that generates random passwords
using the secrets module.

## Features

- Random password generation
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters
- Custom password length
- Input validation

## Tech Stack

- Python
- Secrets Module
- String Module

## How to Run

python password_generator.py

## Concepts Learned

- Python modules
- Functions
- Loops
- String manipulation
- Random selection
- Exception handling
