# Simple Interest Calculator

A Python application that calculates simple interest
and total payable amount.

## Features
- Principal amount input
- Annual interest rate input
- Time duration input
- Simple interest calculation
- Total amount calculation
- Input validation

## Formula

SI = (P * R * T) / 100

## Tech Stack
- Python

## How to Run

python interest_calculator.py
