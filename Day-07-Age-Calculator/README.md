# Age Calculator

A Python application that calculates a person's age
using their date of birth.

## Features

- Calculate age in years
- Calculate total days lived
- Next birthday countdown
- Date validation
- Future date detection

## Tech Stack

- Python
- Datetime Module

## How to Run

python age_calculator.py

## Concepts Learned

- Functions
- Date and time module
- Date calculations
- Conditional statements
- Exception handling
