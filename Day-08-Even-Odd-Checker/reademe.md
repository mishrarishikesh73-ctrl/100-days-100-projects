# Even Odd Checker

A Python program to check whether a number
is even or odd.

## Features

- Even/Odd detection
- Positive/Negative detection
- Zero detection
- Multiple number checking
- Input validation
- Exit option

## Tech Stack

- Python

## How to Run

python even_odd.py

## Concepts Learned

- Functions
- If-elif-else
- Modulo operator
- While loops
- Exception handling
